# Retail Banking Customer Churn & Retention Analytics

An end-to-end data analytics project examining customer attrition in a retail-banking setting using **Python, SQL, statistical analysis, feature engineering, and machine learning**.

## Business Problem

Customer attrition can reduce revenue and increase acquisition costs. This project asks:

> **Which customer characteristics are associated with churn, can we identify customers at elevated churn risk, and what insights could support a targeted retention strategy?**

The goal is not only to build a predictive model, but to translate analysis into clear, decision-relevant insights.

## Project Workflow

1. Data quality assessment and cleaning
2. Exploratory data analysis (EDA)
3. SQL-based customer and segment analysis
4. Feature engineering
5. Classification modelling
6. Model evaluation
7. Interpretation of churn drivers
8. Business recommendations

## Tools

- **Python:** pandas, NumPy, Matplotlib, scikit-learn
- **SQL:** aggregation, segmentation, conditional logic, business queries
- **Analytics:** descriptive statistics, customer segmentation, classification
- **Communication:** visualizations and executive-level recommendations

## Dataset

The project uses a public, anonymized/synthetic-style bank churn modelling dataset containing 10,000 customer records. It includes customer demographics, credit characteristics, account balances, product holdings, activity indicators and an attrition outcome.

**Important:** This is a portfolio project using public data. It does not contain RBC customer information and is not affiliated with or endorsed by RBC.

## Questions Investigated

- What is the overall customer churn rate?
- Which customer segments experience higher churn?
- How do age, geography, balance, product holdings and activity relate to churn?
- Can customer characteristics be used to identify elevated churn risk?
- Which features are most useful in explaining model predictions?
- How could these findings inform customer-retention analysis?
